Interactive, offline trio structural-variant review with igv-reports.
Tracks are ordered child, father, mother from the pedigree and verified BAM
read-group identities. DEL, DUP, INV and BND use paired breakpoint windows;
INS uses one anchor. Original END/SVLEN and source records remain available.
Missing or unmatched sample support is NA, not zero or a reference genotype.
Read size, track height, zoom and pan controls operate within the embedded
read windows. The report embeds IGV.js, reference sequence and BAM slices.
Every input record is accounted for, including explicit skipped-record reasons.
